📥 Download Backup

        

          Saves a .json file of all your store data — products, transactions, expenses, GCash logs, users, and settings.
          Use this file to restore your data or transfer to another device.
        

        
        

      


      

        
        

          
          

            
            
          


          
          

            

              Load a .json backup file you downloaded from this system.

              Use Replace All to fully restore, or Smart Merge to combine data from two devices.
            

            
⏱ Conflict rule: Newer timestamp wins automatically.

            

            

              
            

            

              
              

                
                
              

            

            

            

              
              
            

            

          


          
          

            

              📡 Sync Management tracks an event queue for future cloud sync (Firebase/Supabase).
              It is separate from backup restore — restore loads a .json file while sync pushes/pulls live changes to/from a cloud provider.

💾 Storage Info

          
Where is your data?
Saved in your browser's IndexedDB — on this device only.

          

            
🔄
Survives page refresh
IndexedDB data persists across page refreshes and browser restarts.

            
🚫
Incognito / Private mode
Data is lost when tab closes. Always use regular browser.

            
🧹
Clearing browser data
Clears ALL POS data including IndexedDB. Always download a backup first before clearing.
